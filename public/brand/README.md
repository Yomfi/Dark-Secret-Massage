# Massager Studio brand assets

Derived from the approved official logo JPEG (raster — not a vector original).
Brand identity: **Purple & Black**.

| File | Purpose |
|------|---------|
| `massager-studio-logo-source.jpg` | Source artwork |
| `massager-studio-logo.png` | Transparent mark on light surfaces (black mark + purple wave) |
| `massager-studio-logo-on-dark.png` | Reversed mark for dark surfaces (white mark + purple wave) |
| `favicon.svg` | Purple & black favicon (official mark on a black rounded square) |
| `favicon-16.png` / `favicon-32.png` / `favicon-48.png` | PNG favicon fallbacks |
| `apple-touch-icon.png` / `icon-512.png` | Touch / PWA icons from the same mark |

**Do not** invent lettermarks (e.g. “MS” text icons). Always regenerate from the source JPEG.
